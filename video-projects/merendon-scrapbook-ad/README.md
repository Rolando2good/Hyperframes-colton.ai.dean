# Merendón: "do what works for you" (1080×1920, 30fps)

The runtime follows the voiceover: VO end + 2.4s (the logo lands, then a 1.5s final hold). It is about 28.6s with the current placeholder read.

Scrapbook-style vertical ad built in **Remotion (React + TypeScript)**. Everything (paper, tape, stickers, foley, music) is original and generated by code in `scripts/`.

> This project uses Remotion because the brief asked for it. The rest of the workspace uses the HyperFrames HTML pipeline.

## Swap in the real files (no code changes)

| Put this file here | What happens |
|---|---|
| `public/vo/voiceover.mp3` | the real ElevenLabs "Jess" read (normalize it to about -16 LUFS) |
| `public/vo/words.json` | `[{word, start, end}]` in seconds. All captions, scene cuts, SFX and the music arrangement move to match it |
| `public/logo/merendon.svg` | picked up automatically. Until it exists, a **labeled placeholder** is shown. The logo is never redrawn |

Then run `npm run music` (the beat's filter sweep, drum in/out points and logo bell follow `words.json`), followed by `npm run render`.

The VO and words.json that ship now are **placeholders**: a local Kokoro TTS read of the exact script at 1.12× speed, one whole sentence at a time. Word times are estimated by syllable count and snapped to the pauses detected in the audio.

## Commands

```bash
npm install
npm run studio            # Remotion Studio (live preview)
npm run assets            # textures + stickers + SFX  (python3 + numpy + pillow + soundfile)
npm run music             # Tone.js beat -> public/music/bed.wav (needs Playwright's Chromium)
npm run render            # renders/raw.mp4 -> merendon-ad.mp4 (-14 LUFS) + merendon-hook-preview.gif
node scripts/final-check.mjs   # prints the 5-point final check
node scripts/stills.mjs 0 240 ...  # look-dev stills into renders/stills/
```

## How it's built

- `src/cues.ts` reads words.json and produces the beat grid (84 BPM, 0.714s). Scene cuts snap to the grid.
- `src/plan.ts` is the edit decision list. Every visual event and every SFX is listed there in frames, so picture and sound can't drift apart.
- Stop-motion feel:
  - Paper and stickers move on twos (`onTwos`, `stepPoses`), and nothing eases.
  - Each piece gets a seeded ±4° rotation and ±6px jitter (fixed hand placement plus a ±2px boil on every hold).
  - Paper edges are torn polygons. Tape strips are crooked.
  - Pen strokes are filled outlines with 2–6px pressure.
- Only the camera (drift of about 3px/s, a 1.03 punch on beat drops) and the caption word-pop run at 30fps.
- Audio levels:
  - VO at -16 LUFS.
  - Music bed at -28 LUFS, ducked 6dB while the voice speaks (sidechain from words.json). That puts it about 18 LU under the voice.
  - SFX baked about 10dB under the VO. Each `pop_sticker` uses one of 7 pitches (-3 to +3 semitones), and no pitch plays twice in a row.
  - The final mix is mastered to -14 LUFS / -1 dBTP with two-pass loudnorm.
